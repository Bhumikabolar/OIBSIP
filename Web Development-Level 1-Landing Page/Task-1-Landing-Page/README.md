# NexaAI - AI Landing Page

## About the Project

NexaAI is a modern, responsive static landing page created as part of the
Oasis Infobyte Web Development and Designing Internship.

The website presents an AI-focused technology product through a clean,
modern, and user-friendly interface.

## Features

- Sticky navigation bar
- Responsive hero section
- AI-focused landing page design
- Call-to-action buttons
- Features section with interactive cards
- Statistics section
- About section with AI performance visualization
- Contact call-to-action section
- Footer with navigation and social links
- Hover effects and smooth scrolling
- Responsive design for desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- CSS Media Queries
