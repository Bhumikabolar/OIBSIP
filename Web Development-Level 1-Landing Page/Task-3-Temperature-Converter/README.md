# 🌡️ Temperature Converter

An interactive and responsive Temperature Converter developed as part of the **Oasis Infobyte Web Development and Designing Internship (OIBSIP)**.

## 📌 About the Project

This project allows users to easily convert temperatures between:

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

The application provides instant conversion results through a simple and user-friendly interface.

## ✨ Features

- 🌡️ Convert between Celsius, Fahrenheit and Kelvin
- ⚡ Instant conversion
- 🎨 Clean and modern user interface
- 📱 Responsive design
- 🧮 JavaScript-based calculations
- ❌ Input validation for invalid values
- 🔄 Easy unit selection

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
